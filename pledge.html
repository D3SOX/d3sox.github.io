Pledge

Hold me to it

I build software I need myself. Most of this page follows from that.

When something breaks, I'm usually the first to notice, so bugs, security issues, and breakage from dependency updates get fixed. I can't promise it'll be fast, since I'm one person, but every issue gets looked at. I don't close issues just because they're old.

Most of my projects will stay free. If one ever becomes paid, you pay for me hosting it, not for features: the self-hosted version gets every feature, and you can leave any time and take your data with you.

Open source stays open source. I won't relicense a project you already depend on.

Ending a project is the last resort. If I have to, I'll announce it ahead of time, publish a final release that works, and keep the repository up so someone else can continue it.

This covers the projects I still maintain. Older ones I've stopped working on are marked as such on my homepage.
