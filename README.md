# d3sox.github.io

This is just my website

It's built using [Vite](https://vitejs.dev/) and [Tailwind CSS](https://tailwindcss.com/), and uses the [Catppuccin Mocha color scheme](https://catppuccin.com/palette/#mocha)

The site ships static HTML and CSS with bundled SVG icons and JPEG XL screenshots, with WebP fallbacks for browsers without JPEG XL support. It does not require JavaScript in the browser.
